# Homebrew-Tap

```bash
brew install --cask g7v5jprvzb-web/tap/pdfsucher
```

PDFSucher ist nicht notarisiert. Der Cask entfernt nach der Installation das Quarantäne-Attribut,
damit macOS die App startet. Falls macOS trotzdem warnt: Systemeinstellungen > Datenschutz & Sicherheit > „Trotzdem öffnen“.
